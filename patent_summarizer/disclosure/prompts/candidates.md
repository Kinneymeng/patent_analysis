# 候选发明方案挖掘与融合

根据给出的技术来源，提出 1～5 个有实质技术差异的候选发明方案。材料足够时通常给出 3～5 个；材料只能支持较少方案时如实减少，不得用标题同义改写凑数。

每项必须说明技术问题、核心创新机制、与材料中已有方案或常规做法的初步区别、为什么可以实施、对应的材料定位。允许基于通用工程知识适度补全，但必须将补全内容标为建议实现。

检查候选之间能否通过共享的数据流或控制闭环形成一个更完整的组合方案；需要融合时，直接将融合方案作为候选，并说明组合关系。推荐一个技术闭环最完整、证据最充分且便于实施的候选。

只输出 JSON：

{
  "候选方案": [
    {
      "编号": "C1",
      "标题": "一种……方法及系统",
      "技术问题": "……",
      "核心创新": "……",
      "初步区别": "……",
      "可实施性": "……",
      "材料依据": ["[1]", "[3]"],
      "推荐": true,
      "推荐理由": "……"
    }
  ]
}
