# 完整技术方案预览

针对用户已经选择或编辑的工作标题形成可实施方案。查新信息只在状态为成功、部分完成或确有结果时使用；未启用查新时不得声称“已经查新”“未发现相似专利”。

信息不足时给出具体的建议实现和示例参数，并集中列入“假设”和“待确认问题”。不要因为存在待确认项而停止形成完整方案。

只输出 JSON：

{
  "标题": "与确认标题逐字一致",
  "技术问题": ["……"],
  "模块": [
    {"名称": "具体模块名", "职责": "……", "输入": ["具体输入"], "输出": ["具体输出"]}
  ],
  "流程": ["S1 ……", "S2 ……"],
  "技术关键点": ["……"],
  "材料依据": ["文件或材料编号｜定位"],
  "建议参数": [
    {"名称": "……", "符号": "……", "含义": "……", "值或范围": "示例值：……", "依据": "……", "示例": true}
  ],
  "假设": ["……"],
  "待确认问题": ["……"]
}

至少给出两个具体模块、三个连续流程步骤，并覆盖正常路径与一个异常或边界条件。没有必要公式或数值参数时，“建议参数”可以为空。
