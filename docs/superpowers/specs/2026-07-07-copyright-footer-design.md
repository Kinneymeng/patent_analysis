# EXE 主界面版权页脚设计

## 目标

在专利 DOCX 处理工具的主窗口中持续展示版权信息，使其清晰可见，但不干扰目录选择、任务切换、运行操作与日志阅读。

## 已确认方案

- 位置：白色主面板之外、应用窗口最底部，水平居中。
- 文案：`© 2026 平台及模组开发部 · 线控底盘所 版权所有`
- 不添加“版权信息”标签或其他前缀。
- 样式：使用现有界面的次要文字颜色与微软雅黑 UI 小字号，保持低强调度。
- 行为：始终显示，不响应点击，不随任务模式或运行状态变化。

## 布局

主窗口保持“标题区—主面板—版权页脚”的纵向结构。主面板继续自适应占据主要空间；页脚使用固定的紧凑高度和少量底部留白。窗口默认尺寸与最小尺寸不变，新增页脚所需空间由日志区域弹性吸收。

## 实现边界

仅修改 `patent_summarizer/gui.py` 的主界面布局，不改业务处理、配置、打包方式或版权文案来源。版权文本直接定义为界面常量，无需新增配置项。

## 验证

- 运行现有单元测试。
- 实例化 GUI，确认版权文本、位置、颜色和字体配置正确。
- 检查默认窗口与最小窗口尺寸下，页脚完整显示且不遮挡主面板。
